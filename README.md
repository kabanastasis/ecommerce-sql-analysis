# E-Commerce Sales & Customer Analytics Using SQL

## Project Overview

This project presents an end-to-end analysis of an e-commerce database using MySQL.

The objective was to analyze sales performance, customer behavior, product performance, retention, and key business KPIs in order to generate actionable business insights.

The analysis was performed entirely in SQL using MySQL and includes both fundamental and advanced SQL techniques such as joins, CTEs, window functions, conditional aggregation, customer segmentation, cohort analysis, and Pareto analysis.

---

## Business Objectives

The analysis aims to answer key business questions such as:

- How is revenue changing over time?
- What is the company's Average Order Value?
- Which products and categories generate the most revenue?
- Which products are experiencing declining revenue?
- Which customers generate the most value?
- How are customers distributed across value segments?
- What percentage of customers make repeat purchases?
- How many customers are new versus returning each month?
- How does customer retention change over time?
- Which products account for approximately 80% of revenue?
- How is the order cancellation rate changing?
- How is the overall business performing month-over-month?

## Business Definitions

To maintain consistency across the analysis, the following definitions were used:

- **Revenue:** Revenue generated only from completed orders.
- **Average Order Value (AOV):** Completed-order revenue divided by the number of completed orders.
- **Active Customer:** A customer who completed at least one purchase during a given month.
- **New Customer:** A customer whose first completed order occurred during the current month.
- **Returning Customer:** A customer who completed an order in a previous month and purchased again.
- **Repeat Customer:** A customer with at least two completed orders.
- **Customer Lifetime Value (CLV):** Total completed-order revenue generated by a customer.

### Customer Segments

Customers were segmented based on total spending:

| Segment | Total Spending |
|---|---:|
| High Value | >= 1000 |
| Medium Value | >= 500 and < 1000 |
| Low Value | < 500 |
